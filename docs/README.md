## Documentation Rule For Each Phase

At the end of every phase, create or update a phase log with:

1. Goal and scope.
2. Thought process.
3. Design decisions.
4. AI tools or assistants used.
5. Verification performed.
6. Known limitations or follow-up work.
7. Commit or GitHub status.

This keeps the final README easier to write and gives reviewers a clear audit trail of how the project evolved.
